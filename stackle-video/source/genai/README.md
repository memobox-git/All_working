# 20 Gen AI Concepts You Actually Need, Explained in 2 Minutes (episode 03)

A 2:28 explainer in a hand-drawn notebook style, voiced by the ElevenLabs "Crispus Roshan" voice, with no background music (`"music": false`). Each of the twenty concepts gets its own notebook page:
- a numbered circle;
- a marker title;
- its line, word by word, with the key words highlighted;
- a hand-drawn sketch that builds while the line is spoken;
- a starred takeaway.

A 1→20 tracker by the spiral binding ticks each concept off. The episode opens on the thumbnail and the hook (the notebook's cover page), then the Stackle channel intro, then the twenty pages, and closes on the comment ask. It uses the shared kit in `../explained/` (see its README for the running order and the tools). The look comes from the reference carousel Chris shared, and `style-frame.html` is the approved still it started from.

## How a page is timed

Every page follows the voice. `story.js` finds each number word ("One", "Two" … "Twenty") in the transcript and builds that page around it:

- **The number** pops in just before it is said.
- **The title** is written in on the concept's name, and its marker rays follow.
- **The line** (landscape only) appears word by word with the voice, and each key word is highlighted as it appears.
- **The sketch** builds one step at a time while the line is spoken, and finishes about two seconds before the page turns.
- **The takeaway** lands about 1.5 seconds before the page turns, so the whole page holds still long enough to read (and to screenshot).

To change a concept's wording on screen, edit `CONCEPTS` in `story.js`. A `^` before a word highlights it. To change a sketch, edit its entry in `sketches.js`.
