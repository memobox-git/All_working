# "It's not a checklist. It's a wish list."

This post is adapted from the most-liked post in the Taplio library since September 1: Anton Martyniuk's "Dear recruiters, if you're looking for a .NET developer who knows…" (3,784 likes, 263 comments, 349 shares, Sep 27 2026). It is rewritten for data engineers, with a dollar figure in line 1 and Crispus's hiring-side angle (200+ interviews).

- `post.txt`: the post, also saved as a Taplio draft with the GIF attached (not scheduled).
- `wish-list.gif` / `.mp4` (about 15 seconds, loops): a job posting pinned to the chalkboard. The requirements pile up faster and faster, then the $90K salary appears, then a "3 TEAMS, NOT 1 ENGINEER" stamp lands, and it closes on "It's not a checklist. It's a wish list."
- `source/jd.html`: edit the requirements in `REQ`, then render with `PAGE=jd.html ./render2.sh "?scene=1&step=N" out.png 1` (step 0–12) and `?scene=2` for the closing.
