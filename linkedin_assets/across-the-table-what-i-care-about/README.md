# Across the Table: what I don't care about, and what I do

This is a hiring-side post with an animated chalkboard GIF (about 21 seconds, loops). The format is adapted from Melissa Grabiner's "what I don't care about as a recruiter" post (941 likes, Sep 29 2026). It is rewritten for data engineering interviews, using only facts from the Stackle post guide: 200+ interviews across banking, healthcare, automotive and financial exchanges.

- `post.txt`: the post text, also saved as a Taplio draft with the GIF attached (not scheduled).
- `across-the-table.gif` / `.mp4`: the hook, then 3 things that don't matter (crossed out), then 4 that do (ticked), then the closing line.
- `source/care.html`: edit the lists there, then render with `PAGE=care.html ./render2.sh "?scene=N&step=M" out.png 1`. Scenes: 0 = hook, 1 = don't care, 2 = do care, 3 = closing.
