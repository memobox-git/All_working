# Learn data engineering for $0 (YouTube channels, in order)

Adapted from Abhisek Sahu's "Learn data engineering for free" post (553 likes, Sep 21 2026: https://www.linkedin.com/posts/abhisek-sahu-84a404b1_learn-data-engineering-for-free-youtube-activity-7507687840659439616-Oy6q). His skill-to-channel map is reordered into a numbered learning path with fewer, stronger channels per skill. All 15 channel URLs were checked on Oct 22 2026, and each returned the expected channel.

- `post.txt`: the post with channel links, also saved as a Taplio draft with the GIF attached (not scheduled).
- `learn-de-for-0.gif` / `.mp4` (about 14 seconds): a hub-and-cards graphic in the spirit of Abhisek's flower but in a different style. A numbered clockwise arrow around the YouTube hub grows from 1 to 9 as each card appears, showing the learning order. Then the closing line appears.
- `learn-de-for-0.jpg`: the finished graphic as a still (2160 × 2700).
- `source/hub.html`: edit `STEPS` and `POS`, then render with `PAGE=hub.html ./render2.sh "?step=N" out.png 1` (step 0–10).
