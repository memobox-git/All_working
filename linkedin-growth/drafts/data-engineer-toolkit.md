# Data engineer toolkit (GIF)

Visual: `visuals/data-engineer-toolkit.gif` (1080x1350, 7.5-second loop, 1.5 MB). Everything is on screen from the first frame; only the arrows and the travelling dot move. MP4 fallback: `visuals/data-engineer-toolkit.mp4`. Still: `visuals/data-engineer-toolkit.png`. The older version that builds up from an empty screen is kept as `data-engineer-toolkit-buildup.gif`.

What it shows: "Data Engineer" in the centre, with 8 skill blocks around it in learning order. Arrow badges in the gaps run 1 → 8 and back to the centre, and a data dot travels the path.

| # | Block | Tools (logos) |
|---|---|---|
| 1 | SQL | PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, BigQuery, DuckDB, SQLite, MariaDB |
| 2 | Python | Python, pandas, Polars, NumPy, Jupyter, FastAPI, Pydantic, pytest, scikit-learn |
| 3 | Spark & streaming | Spark, Databricks, Kafka, Flink, Hadoop, Delta Lake, Iceberg, Trino, Hive |
| 4 | Pipelines | Airflow, dbt, Dagster, Prefect, Fivetran, Airbyte, Great Expectations, Kestra, Docker |
| 5 | AWS | S3, Glue, Redshift, EMR, Kinesis, Athena, Lambda, Lake Formation, Step Functions |
| 6 | Vector databases | Pinecone, Qdrant, Weaviate, Chroma, Milvus, pgvector, Elasticsearch, Redis, LanceDB |
| 7 | RAG | LangChain, LlamaIndex, Hugging Face, Unstructured, embeddings (Sentence Transformers), Cohere Rerank, Haystack, Ragas, MCP |
| 8 | LLMs | Claude, OpenAI, Gemini, Llama, Mistral, Bedrock, SageMaker, Ollama, vLLM |
