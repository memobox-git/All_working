## How the scripts are laid out

Each section has a timecode and up to three lines:

- **ON SCREEN** — text or graphics burned into the frame
- **VO** — what Chris says (on camera or voice-over)
- **B-ROLL** — screen recording or footage under the voice

Week videos (4–13) all follow: Hook → Intro → Recorded basics → Live build → How AI is used → What you ship → Next week.

## Rules applied in every script

- Core message, word for word somewhere in each video: **"AI writes the first draft. You learn the judgment that gets you hired."**
- Chris's credentials are only: data engineer for 10+ years, 200+ senior technical interviews from the hiring side. No employer is named.
- Only the approved stats are used, each with its source shown on screen.
- Cohort start is left as **[date]**. Find and replace it before export.
- End card on every video: **stackle.io** + **Book a call** button.
- Video 3 is course-neutral: no course name, price, weeks or tools from this masterclass.
