# Stackle: rules for any visual made in this repo

Read this before making any graphic, infographic, carousel, thumbnail or motion graphic.

## Font
Plus Jakarta Sans (400, 600, 800). It's the same font stackle.io uses.

## Colours: rotate a theme every post

Don't use the same colours twice in a row. Pick the next theme in this list for each new image. What stays the same on every image is the font, the header (avatar, "Chris · Stackle", handle) and the footer with stackle.io. That's what makes the posts recognisable, not the colour.

| Theme | Page | Cards / border | Accent gradient | Text / muted |
|---|---|---|---|---|
| Blue (stackle.io) | `#FFFFFF` | `#F6F8FC` / `#DCE3EE` | `#2563EB → #10A5BE` | `#171717` / `#5B6170` |
| Dark | `#0A0A0A` | white cards `#FFFFFF` / `#27272A` | `#3B82F6 → #22D3EE` | `#FAFAFA` / `#A1A1AA` (dark text inside cards) |
| Emerald | `#FFFFFF` | `#ECFDF5` / `#A7F3D0` | `#059669 → #10B981` | `#171717` / `#5B6170` |
| Violet | `#FFFFFF` | `#F5F3FF` / `#DDD6FE` | `#5757FF → #A855F7` | `#171717` / `#5B6170` |
| Rose | `#FFFFFF` | `#FFF1F2` / `#FECDD3` | `#E11D48 → #DB2777` | `#171717` / `#5B6170` |

Use red `#DC2626` for "wrong / before" and green `#059669` for "right / after" in any theme.

Video and motion graphics use the Dark theme.

Log of what's been used, so the next image picks a different one:

## Never use
Amber/gold `#F59E0B`, `#BA7517`, charcoal `#1E1C1D` and cream `#FAF8F1`. This is the old brown-and-gold video palette, retired on Oct 14, 2026. If any skill or older file says these are "the Stackle colours", this file wins.
