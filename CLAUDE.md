# Stackle: rules for any visual made in this repo

Read this before making any graphic, infographic, carousel, thumbnail or motion graphic.

## Font
Plus Jakarta Sans (400, 600, 800). It's the same font stackle.io uses.

## Colours (taken from stackle.io)

**Light: the default for LinkedIn images, carousels and infographics**
- Background `#FFFFFF`
- Text `#171717`
- Muted text `#5B6170`
- Accent: gradient `#2563EB → #10A5BE` (blue to cyan); solid fallback `#2563EB`
- Cards `#F6F8FC`, borders `#DCE3EE`

**Dark: for video and motion graphics**
- Background `#0A0A0A`
- Text `#FAFAFA`
- Muted text `#A1A1AA`
- Accent: gradient `#3B82F6 → #22D3EE`; solid fallback `#3B82F6`

**Secondary accent (use sparingly):** violet `#5757FF`

## Never use
Amber/gold `#F59E0B`, `#BA7517`, charcoal `#1E1C1D` and cream `#FAF8F1`. This is the old brown-and-gold video palette, retired on Oct 14, 2026. If any skill or older file says these are "the Stackle colours", this file wins.
